# Skill: Documentación del Proyecto

## Objetivo

Mantener documentación suficiente para comprender, utilizar y continuar el proyecto sin depender del contexto de la conversación con el agente.

---

## Principio fundamental

La documentación debe explicar decisiones y funcionamiento real.

No documentar funcionalidades que todavía no existen.

---

## README

El README principal debe explicar:

- propósito;
- características;
- requisitos;
- cómo ejecutar;
- estructura básica;
- cómo actualizar preguntas;
- cómo realizar una simulación.

---

## Arquitectura

Documentar cuando sea necesario:

```text
datos
  ↓
motor
  ↓
interfaz
```
