# Skill: Interfaz y Experiencia de Usuario

## Objetivo

Crear una interfaz clara, sencilla y agradable para estudiar y practicar el examen teórico de conducir.

La prioridad es la facilidad de uso, no la complejidad visual.

---

## Usuario principal

La aplicación será utilizada por una persona que desea practicar para un examen teórico de conducir.

La interfaz debe poder utilizarse sin conocimientos técnicos.

---

## Principios de diseño

Priorizar:

1. Claridad.
2. Legibilidad.
3. Simplicidad.
4. Accesibilidad.
5. Consistencia.
6. Feedback inmediato.
7. Bajo número de elementos innecesarios.

---

## Pantallas principales

Como mínimo puede existir:

### Inicio

Debe permitir:

- comenzar práctica;
- comenzar simulación;
- seleccionar categoría si corresponde;
- consultar instrucciones.

### Pregunta

Debe mostrar:

- progreso;
- pregunta;
- opciones;
- acción para continuar;
- feedback cuando corresponda.

### Resultado

Debe mostrar:

- resultado;
- cantidad de respuestas correctas;
- cantidad incorrectas;
- porcentaje;
- opción para volver a practicar.

---

## Preguntas multiple choice

Las opciones deben ser visualmente claras y fáciles de seleccionar.

Preferir botones o tarjetas completas antes que pequeños radio buttons difíciles de seleccionar.

Ejemplo conceptual:

```text
┌──────────────────────────────────────┐
│ A                                    │
│ Texto de la respuesta                │
└──────────────────────────────────────┘

┌──────────────────────────────────────┐
│ B                                    │
│ Texto de la respuesta                │
└──────────────────────────────────────┘
```
